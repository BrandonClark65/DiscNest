## Adding New Documentation

When adding new documentation:

1. Create an appropriate subdirectory if needed (e.g., `docs/api/`, `docs/architecture/`)
2. Use descriptive filenames with `.md` extension
3. Update this README with a link to the new documentation
4. Consider adding a reference in the main `README.md` if it's important for developers
